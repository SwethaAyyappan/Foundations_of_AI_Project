
============================================================
FIXED VS ADAPTIVE AI EXPERIMENT
============================================================

Project: Adaptive Opponent Modeling in Leduc Hold'em
Environment: RLCard - Leduc Hold'em

EXPERIMENT CONFIGURATION
------------------------
Games per condition: 500
Opponent strategies:
1. Aggressive
2. Conservative
3. Random

Agents compared:
- Fixed Agent: Decision policy without learned opponent estimates.
- Adaptive Agent: Decision policy using Bayesian opponent estimates.

Evaluation metrics:
- Average payoff
- Win rate
- Number of wins
- Number of losses
- Number of ties

============================================================
3. OBSERVATIONS
============================================================

1. The adaptive agent achieved a higher average payoff
   against aggressive opponents.

2. The adaptive agent also performed better against
   conservative opponents.

3. Against random opponents, the fixed agent performed
   slightly better.

4. The Bayesian opponent model learned different action
   distributions for different opponent strategies.

5. Opponent estimates were used by the decision policy
   to estimate hand ranges and calculate expected values.

============================================================
4. CONCLUSION
============================================================

Opponent modeling improved the performance of our
adaptive agent against aggressive and conservative
opponents in these experiments.

However, adaptation did not improve performance against
every opponent strategy.

The results suggest that Bayesian opponent modeling can
help an agent exploit predictable opponent behavior,
although its effectiveness depends on the opponent.

============================================================
5. EXPERIMENT LIMITATIONS
============================================================

- Each condition used 500 games.
- Fixed and adaptive runs were not paired using identical
  random seeds.
- Statistical significance has not been established.
- The decision policy uses heuristic hand-range and
  expected-value approximations.
- Results may vary across random seeds.
